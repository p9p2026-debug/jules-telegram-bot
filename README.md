# 🤖 Jules by Google - Advanced Telegram AI Agent

مستودع برمجي متكامل واحترافي لبوت تيليجرام ذكي مدعوم بوكيل الذكاء الاصطناعي البرمجي **Jules by Google** ونماذج **Gemini (Gemini 3.1 Pro & Gemini 3.6 Flash)**، مبني وفق أحدث معايير الهيكلية النظيفة (Clean Architecture)، ومجهز للنشر الفوري بنقرة واحدة (**One-Click Deployment**) على منصة **Render** والمزامنة المباشرة مع **GitHub**.

---

## 🌟 أبرز مميزات المشروع

### 1. 🚀 البنية السحابية والنشر البسيط (Render & GitHub)
- **توافق 100% مع الخطة المجانية لمنصة Render (Web Service)**: يتضمن البوت خادماً غير متزامن مدمجاً لفحص الصحة (`HTTP Health Server`) يستمع تلقائياً لمنفذ `$PORT` على المسار `/health` لتجنب خطأ انقطاع الفحص (Port Scan Timeout) دون الحاجة لترقية مدفوعة.
- **دعم تشغيل كـ Background Worker**: إمكانية العمل المباشر كعامل خلفية في الخطط السحابية.
- **ملفات نشر جاهزة**: يتضمن `render.yaml` (Blueprint نشر بنقرة واحدة)، و `Dockerfile` عالي الكفاءة، و `Procfile`، و `requirements.txt`.

### 2. 🧠 ميزات وكيل Jules by Google البرمجي
- **التبديل السلس بين النماذج**: أزرار تفاعلية للتبديل الفوري بين:
  - ⚡ **Gemini 3.6 Flash**: فائق السرعة للاستفسارات والمهام اليومية.
  - 🧠 **Gemini 3.1 Pro**: تفكير برمجي معمق لحل المشكلات البرمجية المعقدة.
- **تحليلات برمجية كاملة في الشات**: استلام الأكواد والشروحات والحلول مباشرة داخل المحادثة، مع دعم تقطيع الرسائل الطويلة الذكي وحفظ وسوم الأكواد دون تشويه التنسيق.
- **دعم الوسائط المتعددة والمستندات البرمجية (Multimodal)**:
  - تحليل مستندات الأكواد والملفات: `PDF`, `Markdown (.md)`, `Python (.py)`, `JavaScript`, `JSON`, إلخ.
  - تحليل الصور والمخططات الهيكلية والمعمارية واستخراج الحلول منها.
- **إدارة الجلسات التفاعلية (Sessions Management)**:
  - إنشاء جلسات متعددة ومستقلة لكل مستخدم (`/new`).
  - استعراض الجلسات السابقة والتبديل بينها واستئناف السياق القديم أو حذفها (`/sessions`).
- **تنسيق غني واقتباسات قابلة للطي**:
  - كتل برمجية ملونة بلغات البرمجة المختلفة.
  - اقتباسات موسعة وقابلة للطي (`Expandable Blockquotes`).
  - مؤشرات التفاعل الحية أثناء المعالجة (`Typing...`, `Uploading Document...`).
- **إدارة مفاتيح API الفردية**: إمكانية إدخال كل مستخدم لمفتاح Google API الخاص به عبر المحادثة (`/apikey`) لتفادي استهلاك الحصة العامة.

### 3. 👑 لوحة تحكم الأدمن ونظام الصلاحيات التفصيلي (Granular Permissions)
- **لوحة إدارية تفاعلية عبر الأمر `/admin`**.
- **وضع الصيانة (Maintenance Mode)**: إغلاق البوت بضغطة زر عن العامة وإبقاؤه متاحاً للمشرفين فقط أثناء التحديثات.
- **وضع القائمة البيضاء (Whitelist Mode)**: حصر استخدام البوت بالمستخدمين المعتمدين فقط.
- **التحكم الشامل في الميزات (Feature Toggles)**: إمكانية إيقاف أو تشغيل أي ميزة للجميع:
  - تبديل النماذج (`switch_model`).
  - استخدام نموذج Gemini 3.1 Pro (`use_pro`).
  - رفع وتحليل الملفات والمستندات (`upload_files`).
  - إرسال وتحليل الصور (`send_images`).
  - إنشاء وإدارة جلسات متعددة (`create_sessions`).
  - استخدام مفاتيح API خاصة (`custom_keys`).
- **تخصيص الصلاحيات لكل مستخدم بشكل منفصل (Per-User Granular Overrides)**:
  - البحث عن أي مستخدم عبر معرفه الرقمي `User ID` أو اسمه `Username` عبر أمر `/search`.
  - منح مستخدم معين ميزات خاصة ومحظورة عن بقية المستخدمين.
  - حرمان مستخدم من ميزة محددة فقط (مثل منعه من رفع الملفات والصور مع استمرار قدرته على الدردشة النصية).
  - حظر المستخدم بالكامل (Blacklist) أو إضافته للقائمة البيضاء (Whitelist).
- **قاعدة بيانات خفيفة وسحابية (SQLite)**:
  - حفظ كامل للجلسات، والمستخدمين، والإعدادات، والصلاحيات مع دعم ربطها بقرص دائم (Render Persistent Disk) أو محلياً.

## 📂 هيكلية المشروع (Clean Architecture)

```
jules-telegram-bot/
├── config.py                 # قراءة المتغيرات البيئية والثوابت
├── main.py                   # نقطة تشغيل البوت وخادم فحص الصحة
├── render.yaml               # ملف نشر Render بنقرة واحدة (Blueprint)
├── Dockerfile                # ملف بناء حاوية Docker السحابية
├── Procfile                  # دعم التشغيل كـ Web أو Worker
├── requirements.txt          # الحزم والمكتبات المعتمدة
├── .env.example              # نموذج المتغيرات البيئية
├── .gitignore                # استثناءات Git
├── README.md                 # دليل الاستخدام والنشر الشامل
│
├── database/                 # طبقة قاعدة البيانات
│   ├── db.py                 # التهيئة والاتصال الآمن بـ SQLite
│   └── repositories.py       # مستودعات البيانات (Users, Permissions, Sessions, Settings)
│
├── services/                 # طبقة الخدمات والمنطق البرمجي
│   ├── jules_service.py      # محرك Google GenAI / Jules وربط النماذج والسياق
│   ├── permission_service.py # محرك حساب الصلاحيات التفصيلية
│   └── format_service.py     # معالجة التنسيق، الاقتباسات القابلة للطي، وتقطيع الرسائل
│
├── handlers/                 # معالجات أحداث تيليجرام
│   ├── user_handlers.py      # أوامر المستخدم والدردشة والوسائط
│   ├── admin_handlers.py     # لوحة تحكم /admin وإدارة الصلاحيات
│   └── error_handlers.py     # معالجة الأخطاء الاستثنائية دون توقف البوت
│
└── utils/                    # الأدوات المساعدة
    ├── keyboards.py          # لوحات المفاتيح التفاعلية (User & Admin Keyboards)
    └── server.py             # خادم فحص الصحة HTTP لـ Render
```

## 🛠️ المتغيرات البيئية (Environment Variables)

| المتغير | الوصف | إلزامي؟ | مثال / القيمة الافتراضية |
| :--- | :--- | :---: | :--- |
| `BOT_TOKEN` | توكن البوت الذي تحصل عليه من [@BotFather](https://t.me/BotFather) | **نعم** | `7123456789:AAF_example...` |
| `ADMIN_IDS` | المعرفات الرقمية للمشرفين مفصولة بفاصلة | **نعم** | `12345678,87654321` |
| `GEMINI_API_KEY` | مفتاح Google Gemini الرئيسي من [Google AI Studio](https://aistudio.google.com/app/apikey) | **نعم** | `AIzaSy...` |
| `MODEL_PRO_ID` | معرف نموذج Pro في جوجل | لا | `gemini-2.5-pro` |
| `MODEL_FLASH_ID` | معرف نموذج Flash في جوجل | لا | `gemini-2.5-flash` |
| `DATABASE_PATH` | مسار ملف قاعدة بيانات SQLite | لا | `data/jules_bot.db` |
| `PORT` | المنفذ المخصص لخادم فحص الصحة (تحدده Render تلقائياً) | لا | `8080` أو `10000` |

## 🚀 طريقة النشر السحابي على Render (بأسهل وأبسط طريقة)

### الخطوة 1: الرفع إلى مستودع GitHub
1. افتح مجلد المشروع في سطر الأوامر (Terminal / PowerShell):
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Jules Telegram Bot"
   ```
2. أنشئ مستودعاً جديداً على حسابك في GitHub (اجعله `Private` أو `Public`).
3. اربط المستودع وارفعه:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

### الخطوة 2: النشر المباشر على Render

#### الخيار (أ) - النشر بنقرة واحدة عبر Blueprint (الأسهل والأسرع):
1. سجّل الدخول إلى منصة [Render.com](https://render.com).
2. اضغط على زر **New +** ثم اختر **Blueprint**.
3. اختر مستودع GitHub الخاص بك.
4. ستتعرف المنصة تلقائياً على ملف `render.yaml`.
5. سيُطلب منك إدخال المتغيرات الثلاثة الأساسية:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `GEMINI_API_KEY`
6. اضغط **Apply** وسيتم بناء البوت وتشغيله كـ **Web Service مجانية** فوراً!

#### الخيار (ب) - النشر اليدوي كـ Web Service (الخطة المجانية Free Tier):
1. في لوحة تحكم Render، اضغط **New +** ثم **Web Service**.
2. اختر مستودع GitHub الخاص بك.
3. املأ البيانات التالية:
   - **Name**: `jules-telegram-bot`
   - **Environment**: `Python`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
   - **Plan**: `Free`
4. في قسم **Advanced -> Environment Variables** أضف:
   - `BOT_TOKEN` = `توكن بوتك`
   - `ADMIN_IDS` = `معرف حسابك في تيليجرام`
   - `GEMINI_API_KEY` = `مفتاح Google API الخاص بك`
5. اضغط **Create Web Service**، وستلاحظ أن البوت يعمل ويجتاز فحص الصحة `/health` بنجاح!

## 💻 التشغيل المحلي (Local Development)

1. استنسخ المستودع وادخل المجلد:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   cd YOUR_REPOSITORY
   ```
2. أنشئ بيئة افتراضية وفعّلها:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux / Mac:
   source .venv/bin/activate
   ```
3. ثبّت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
4. انسخ ملف الإعدادات واملأ القيم الخاصة بك:
   ```bash
   cp .env.example .env
   ```
5. شغّل البوت:
   ```bash
   python main.py
   ```

## 🎮 دليل استخدام أوامر البوت

### أوامر المستخدمين العامة:
- `/start`: بدء استخدام البوت، وعرض معلومات النموذج والجلسة ولوحة الأزرار.
- `/help`: عرض دليل المساعدة وشرح الإمكانيات.
- `/model`: التبديل بين نموذج Gemini 3.6 Flash و Gemini 3.1 Pro.
- `/new`: بدء جلسة برمجة جديدة تماماً وتصفير السياق المؤقت.
- `/sessions`: عرض قائمة الجلسات، التبديل بينها، أو حذف أي منها.
- `/apikey <key>`: تعيين مفتاح Google Gemini خاص بك لتجنب الحصص المشتركة.
- `/apikey clear`: مسح مفتاحك الخاص والعودة للافتراضي.
- إرسال الصور: يحلل Jules المخططات الهيكلية، وتصاميم واجهات المستخدم، والمخططات البرمجية.
- إرسال الملفات البرمجية ومستندات PDF: يقدم Jules تحليلاً كودياً دقيقاً واقتراحات تحسين وتصحيح للأخطاء في نفس الشات.

### أوامر المسؤولين (Admins):
- `/admin`: فتح لوحة الإدارة الشاملة للتحكم في الصيانة، والقوائم البيضاء، والميزات العامة.
- `/search <ID أو Username>`: البحث عن أي مستخدم لإدارة صلاحياته التفصيلية، منحه ميزات خاصة، أو حظره من ميزة محددة أو من البوت كلياً.
